# Ads Landing Page — PPC Landing Page Builder
## Triggers: landing page, build landing page, ads landing, ppc landing, lp audit, conversion page

## FRAMEWORK
- Above fold: headline + subhead + hero image + primary CTA
- Trust: logos, reviews count, guarantee badge
- Benefits: 3 bullets (not features)
- Social proof: testimonials with name/photo/result
- FAQ: 5 objections answered
- CTA x3: top, mid, bottom

## SCORING (before delivery)
- Load speed <3s · Mobile first · Single CTA · Heatmap ready
- GTM tag present · Thank-you page event · Form validation
