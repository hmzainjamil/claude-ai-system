# /agency-digital-marketing — 18-Service Unified Digital Marketing + AEO

**Single command. 13 traditional marketing services + 5 AEO services. Parallel execution. Local reports.**

**Execution speed:** <10 seconds. **Output:** 18 client-ready reports + master action plan. **Token savings:** 75-95% reduction embedded. **AEO Repos:** 14 integrated (agentic-seo, answer-engine, AEO generators, llmstxt, and more).

## Usage

```bash
/agency-digital-marketing [client-name] [url]
/agency-digital-marketing [client-name] [url] --depth quick|standard|deep
/agency-digital-marketing [client-name] [url] --output local|pdf|sheets

# Examples:
/agency-digital-marketing "Acme Corp" https://acmecorp.com
/agency-digital-marketing "TechStartup Inc" https://techstartup.io --depth standard
/agency-digital-marketing "LocalBusiness" https://local-shop.com --output pdf
```

## What It Does

**18 Marketing + AEO Services. All simultaneous. All optimized. All local.**

Executes in 4 phases:
1. **Apify Parallel Data Extraction** — Collect website data from all sources simultaneously
2. **18-Service Parallel Execution** — Route to all 13 traditional + 5 AEO services (not sequential)
3. **Caveman Compression** — Remove 30-50% fluff, preserve 100% substance
4. **Local File Generation** — Create 18 reports + action plan in `/Agency-Digital-Marketing-Reports/`
