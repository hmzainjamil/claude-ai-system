## EXECUTION RULES

1. **Load business context FIRST** — always. Never skip. This is what separates generic output from business-specific output.
2. **Strict sequential order** — complete each workflow before the next begins. GBP → Website → Authority → Content.
3. **Chrome must be logged in** — SEMrush, Ahrefs, GSC, GA4, GBP before any tool-using prompt.
4. **Never export Ahrefs CSVs** — burns credits. Copy from visible UI only.
5. **Output formats**: spreadsheets for comparisons, exact copy (not instructions) for all written fixes.
6. **Quick wins first** — impact high → medium → low within each workflow.
