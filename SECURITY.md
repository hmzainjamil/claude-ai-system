# Security & API Keys Notice

All API keys, tokens, and secrets in this repository have been **intentionally removed** and replaced with `[REDACTED]` or `YOUR_KEY_HERE` placeholders.

## To use these skills/workflows:

Each skill that requires API keys will show placeholder values. Replace them with your own keys from the respective providers:

| Service | Where to get |
|---|---|
| Airtable | airtable.com/account → API |
| Apollo | app.apollo.io → Settings → API |
| Apify | apify.com → Settings → Integrations |
| OpenRouter | openrouter.ai/keys |
| Groq | console.groq.com/keys |
| Gemini | aistudio.google.com/app/apikey |
| OpenAI | platform.openai.com/api-keys |
| GitHub | github.com/settings/tokens |

## Installation

Clone any repo and follow the README. All tool configurations require your own API keys — never share your keys publicly.

```bash
git clone https://github.com/hmzainjamil/claude-ai-system
cd claude-ai-system
# Follow setup instructions in each skill's SKILL.md
```

*API keys are provider-issued credentials. This repo contains no real credentials.*
